# نظام متتبع الصحة والعادات (Health Tracker System)

نظام ويب بلغة **PHP** وقاعدة بيانات **MySQL** لتسجيل ومتابعة الأنشطة والعادات الصحية اليومية (مشي، جري، ماء، نوم، تأمل، قراءة...)، مع لوحة إحصائيات عامة وأسبوعية.

**إعداد:** كرم صالحة — 1301211711

---

## نظرة عامة

يوفر النظام واجهة عربية كاملة (RTL) بتصميم وردي متدرج، وتغطي:

- تسجيل الدخول والخروج (حماية الوصول للنظام بجلسة Session)
- لوحة تحكم تعرض إحصائيات عامة (إجمالي السجلات، أيام المتابعة، أفضل نشاط) وإحصائيات الأسبوع الحالي
- عرض جميع السجلات الصحية المسجّلة
- إضافة / تعديل / حذف لكل سجل نشاط صحي

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| PHP | منطق الخادم (Server-Side) |
| MySQL / MySQLi (procedural) | تخزين السجلات الصحية والتعامل معها |
| HTML5 / CSS3 | واجهات المستخدم، بدعم كامل لاتجاه RTL |
| Font Awesome / Google Fonts (Tajawal) | الأيقونات والخطوط عبر CDN |
| PHP Sessions | إدارة جلسة تسجيل الدخول |

## هيكلية المشروع

```
Health-Tracker-System/
├── config.php          # الاتصال بقاعدة البيانات + دالة تسجيل الدخول + دوال الإحصائيات
├── health_db.sql        # بنية قاعدة البيانات + بيانات أولية (10 سجلات)
├── login.php            # صفحة تسجيل الدخول
├── logout.php           # تسجيل الخروج
├── index.php            # لوحة التحكم / الإحصائيات العامة والأسبوعية
├── activities.php       # عرض جميع السجلات + نموذج الإضافة + روابط التعديل والحذف
├── add_activity.php     # إدراج نشاط صحي جديد
└── edit_activity.php    # تعديل نشاط موجود
```

## قاعدة البيانات

قاعدة البيانات `health_habits_db` تحتوي على جدول رئيسي `health_logs` بالحقول التالية:

| الحقل | النوع | الوصف |
|---|---|---|
| id | INT (PK) | معرّف تلقائي الزيادة |
| activity_type | ENUM | walk, run, gym, yoga, meditation, water, sleep, weight, reading, learning |
| value | DECIMAL(10,2) | القيمة الرقمية للنشاط |
| unit | ENUM | minutes, hours, km, cups, kg, pages |
| notes | TEXT | ملاحظات حرة |
| date | TIMESTAMP | تاريخ ووقت تنفيذ النشاط |
| created_at | TIMESTAMP | تاريخ إنشاء السجل |

لا يوجد جدول مستخدمين منفصل؛ يتم التحقق من بيانات الدخول مباشرة داخل دالة `login()` في `config.php`.

## متطلبات التشغيل

- خادم ويب يدعم PHP (مثل Apache عبر **XAMPP** أو **WAMP**)
- PHP 7.4 أو أحدث، مع تفعيل امتداد `mysqli`
- MySQL / MariaDB
- اتصال بالإنترنت لتحميل خطوط Google Fonts وأيقونات Font Awesome (تُحمَّل عبر CDN)

## طريقة التشغيل

1. تثبيت بيئة خادم محلي مثل XAMPP وتشغيل خدمتي Apache و MySQL.
2. نسخ مجلد المشروع إلى مجلد الخادم المحلي (مثل `htdocs` في XAMPP).
3. فتح **phpMyAdmin** واستيراد ملف `health_db.sql` لإنشاء قاعدة البيانات `health_habits_db` وتعبئتها بالبيانات الأولية.
4. التأكد من إعدادات الاتصال بقاعدة البيانات في `config.php`:
   ```php
   define('DB_SERVER', 'localhost');
   define('DB_USERNAME', 'root');
   define('DB_PASSWORD', '');
   define('DB_NAME', 'health_habits_db');
   ```
5. فتح المتصفح على مسار المشروع، مثل: `http://localhost/Health-Tracker-System/login.php`
6. تسجيل الدخول باستخدام:
   - **اسم المستخدم:** `health`
   - **كلمة المرور:** `health123`

## ملاحظات ومجالات للتحسين

- بيانات الدخول (`health` / `health123`) مكتوبة مباشرة داخل الكود لأغراض توضيحية، وليست مخزّنة في قاعدة بيانات مستخدمين ولا مُشفّرة.
- جميع استعلامات الإدراج والتعديل والحذف (`add_activity.php`، `edit_activity.php`، `activities.php`) تُبنى بدمج مباشر لمدخلات المستخدم ضمن نص SQL دون `Prepared Statements`، ما يُعرّض النظام لثغرات SQL Injection — وهذه نقطة تحتاج معالجة قبل أي استخدام إنتاجي.
- الحذف في `activities.php` نهائي ومباشر (Hard Delete) دون تأكيد أو إمكانية استرجاع.
- لا يوجد نظام مستخدمين متعدد أو صلاحيات مختلفة.
- يمكن مستقبلًا إضافة: رسوم بيانية لتطور الأنشطة، تنبيهات وأهداف يومية، وتصدير التقارير الصحية.
